# PeriodPal – Your Personal Cycle Monitor  

## Overview  
**PeriodPal** is a **comprehensive menstrual cycle tracking app** designed to empower women with **accurate and insightful information** about their health. By entering your **last period date** and **average cycle length**, PeriodPal precisely calculates:  
- **Your next expected period date**  
- **Your potential ovulation window**  

This tool helps users **anticipate changes, track symptoms, and identify patterns**, enabling better health and wellness decisions. Whether for **health monitoring** or **family planning**, PeriodPal is your trusted cycle management companion.  

## Features  
- **Accurate Period Predictions**: Get precise forecasts for your upcoming menstrual cycles.  
- **Fertility Window Insights**: Identify your **most fertile days** for family planning or natural contraception.  
- **Symptom Tracking**: Monitor cycle-related symptoms and patterns over time.  
- **User Privacy Protection**: Your personal data is secure, ensuring a **private and convenient** experience.  
- **Easy-to-Use Interface**: A simple, intuitive design makes cycle tracking effortless.  

## Technologies Used  
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express  
- **Database:** MongoDB (for storing user data securely)  
- **API Integration:** Date calculations and cycle prediction algorithms  

## Installation  

### Prerequisites  
- **Node.js** and **npm** installed on your system  

### Steps  
1. **Clone the Repository:**  
   ```bash
   git clone <repository-url>
   cd PeriodPal
2. **Install Dependencies:**
   ```bash
    npm install
3. **Run the Application:**
   ```bash
    npm start
4. **Access the Web App:**
  Open your browser and visit http://localhost:3000 to start tracking your cycle with PeriodPal.
